Create and manage a structured task list for the current session.
- Actions: add, update, list
- Track progress: pending, in_progress, completed, cancelled
- Use before starting multi-step work to plan steps
- Keep exactly one item in_progress at a time

CRITICAL RULES:
- You MUST call update with status "in_progress" when you START working on a task
- You MUST call update with status "completed" IMMEDIATELY after finishing a task — do NOT wait
- You MUST call update with status "cancelled" if a task is no longer needed
- Never leave completed tasks in pending or in_progress state
